## Análise de Dados

Minha abordagem começa pela compreensão do problema por trás dos números.
Gosto de dividir problemas pouco claros em perguntas, identificar os dados
necessários, investigar as evidências e comunicar os resultados de forma que
possam apoiar uma decisão.

### Minha Abordagem

**Problema → Perguntas → Dados → Limpeza → Exploração → Evidências → Visualização → Comunicação → Decisão**

Gosto especialmente de limpeza, tratamento e exploração de dados. Procuro
valores nulos, duplicatas e inconsistências, mas também questiono se o
primeiro resultado realmente representa o problema.

Para mim, uma análise não termina em um número. Quero entender o que
aconteceu, por que aconteceu e, quando relevante, quando aconteceu. Também
considero quem receberá a informação e adapto a visualização e a comunicação
ao público.

> *“Uma boa análise é aquela que faz o stakeholder pensar:
> ‘Era isso que estava causando o problema — eu não tinha percebido.’”*
